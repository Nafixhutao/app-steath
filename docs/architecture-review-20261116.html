Problem: tiga belas module masing-masing mendekode envelope yang sama — interface transportnya nyaris selebar implementasinya (shallow), dan 38 nama type diketik dua kali dengan semantik timestamp berbeda (Date vs string).

Solution: satu module transport (decode envelope, normalisasi error, tipe wire) di belakang seam tunggal; client resource menjadi binding tipis di atasnya.

  • locality: decode + error di satu tempat
  • leverage: satu interface, 13 caller
  • interface menyusut; implementation menyerap decoder
  • type kembar Date/string menyatu

Catatan: menggabungkan 11 client tanpa memperdalam transportnya hanya memindahkan 1.229 baris. Perdalam transportnya dulu; kontrak REST terbuka (OpenAPI) menyusul sebagai keputusan terpisah.
